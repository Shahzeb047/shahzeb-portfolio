# Shahzeb Ali — Premium Portfolio

## Files
- `index.html` — complete website
- `profile.jpeg` — your uploaded profile photo

## Run
Just double-click `index.html`, or open it with a local server.

Recommended in VS Code:
1. Open this folder.
2. Use Live Server, or run any local static server.
3. Open the local URL in your browser.

## Where to edit
Open `index.html` and search for the sections/content you want to change.
The main personal details are near the top of the HTML and are also visible directly in the page content.

## Important
The contact form currently uses `mailto:` so it opens the visitor's email application. It does not pretend to send through a backend.

## Replace project links
The three project cards currently point to your GitHub profile. Replace each with the actual repository URL when you have the individual repositories ready.

## Profile photo
The Hero and About sections use `profile.jpeg`. Replace that file with another image using the same filename if you want to change the photo.
